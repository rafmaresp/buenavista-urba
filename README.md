# Buenavista I · Incidencias

Web de incidencias de la urbanización Buenavista I (Dos Hermanas): farolas fundidas, baches, fugas y otros avisos, con panel de gestión para la junta.

Stack: Angular + Leaflet (front), Azure Functions .NET 10 isolated (API), Azure Table Storage, desplegado en Azure Static Web Apps.

Ver `CLAUDE.md` para requisitos, reglas de privacidad y convenciones.
